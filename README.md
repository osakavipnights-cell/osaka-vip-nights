# Osaka VIP Nights — Updated website

Open this folder in VS Code and preview `index.html` with a local web server (for example, VS Code Live Server). The language files are loaded with `fetch`, so opening the file directly with `file://` will not load language switching in many browsers.

The source includes the existing image library, updated English/Japanese/Chinese/Korean copy, responsive styling, SEO metadata, Schema.org JSON-LD, `robots.txt`, and `sitemap.xml`.
